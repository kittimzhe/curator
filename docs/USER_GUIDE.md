# 洞察织机 InsightLoom · 使用手册

> 适用版本:2026-09(P2b)。本手册只写**已实现并验证过**的功能。
> 30 秒了解:你把内容丢进收件箱 → 五个 AI Agent 加工(分类/摘要/互链/质疑/组装)→ **你审批** → 沉淀为纯 Markdown 笔记,自动建立语义索引与知识图谱。

---

## 1. 启动

### 方式 A · 本机运行(推荐日常使用)

```bash
cd insightloom
.venv/bin/uvicorn server.app:app --port 8300
# 打开 http://127.0.0.1:8300
```

`.env` 里已配置真实模型时自动进入真实模式;删除 `.env` 里的 Key 或设置 `INSIGHTLOOM_LLM_MOCK=1` 则回到 MOCK 演示模式。

### 方式 B · Docker

```bash
docker compose up -d        # 零配置 MOCK 模式
```

数据持久化在宿主机 `./data`(数据库/索引)与 `./vault`(你的笔记)。

### 模式说明

| 模式 | 配置 | 适合 |
|---|---|---|
| MOCK | 无 Key | 演示、开发、跑 CI |
| **GLM-4-Flash** | 智谱 Key(永久免费) | **日常推荐** |
| DeepSeek / 任意 OpenAI 兼容 | 改 `.env` 三行 | 按需 |

## 2. 界面总览

顶栏三个标签页 + 右上角两个小控件:

| 区域 | 作用 |
|---|---|
| 🛠 **工作台** | 投递、看流水线、审批提案、检索问答、书签采集入口 |
| 🕸 **图谱** | 知识网络可视化(拖拽/点选/高亮) |
| 🌻 **今日简报** | 园丁巡库、统计卡片、高频标签 |
| 🌙 主题按钮 | 浅色 / 深色 / 跟随系统 三态循环,记忆在浏览器 |
| LLM 徽章 | 显示当前模式(mock / glm-4-flash / …) |

工作台从上到下:Hero 区(含搜索框与书签按钮)→ **流水线舞台条**(内容走到哪一站,哪一站点亮)→ 投递表单 → 事件时间线 → 审批台。

## 3. 采集:把内容放进收件箱(三种姿势)

### ① 页面投递表单(最直接)
工作台投递区填标题 + 正文(+可选链接),回车或点投递。
**快捷键**:正文框内 `⌘/Ctrl + Enter` 直接投递;草稿自动暂存,误刷新不丢。

### ② 书签脚本(任何浏览器)
工作台 Hero 区找到「🌾 织入织机」橙色按钮 → **按住拖到浏览器书签栏**。
之后在任意网页:选中想存的文字(不选则自动取页面描述)→ 点书签 → 弹出「已织入」小窗,2 秒自动关闭。

### ③ 浏览器插件(Chrome/Edge,最顺手)
1. `chrome://extensions` → 开发者模式 → 「加载已解压的扩展程序」→ 选仓库 `web_extension/`
2. 点插件图标 → 服务地址(默认 `http://127.0.0.1:8300`)→ **测试连接** → 保存
3. 任意网页:选文字 → 右键 → **「🌾 织入洞察织机(选中文字)」**,右下角系统通知确认
   (不选中直接右键页面 → 「织入整页」抓标题+正文)

> 三种姿势殊途同归:进入收件箱 → 流水线开工,顶部舞台条开始亮灯。

## 4. 审批:唯一需要你动脑的 30 秒

流水线跑完,审批台出现**提案卡**,包含:

- **摘要**:摘要员写的三句话
- **建议双链**:链接员从既有笔记挑的 `[[关联]]`(语义检索+LLM 双重筛选)
- **质疑结论**:⚠️ 重点看这里
  - `pass` = 质疑员没发现问题
  - `questioned` = **有存疑理由,先读理由再决定**(真实模型下常见,这是产品灵魂)

**操作**:「批准」→ Markdown 落盘 `vault/` + 自动建索引 + 进图谱;「拒绝」→ 留档不写盘。

> 原则:**不点击,不写盘**。你的知识库永远只有你亲手批准过的内容。

## 5. 检索与问答

Hero 区搜索框,两个按钮两种玩法:

- **🔍 检索**:本地语义搜索,返回最相关的**小节**(不是整篇),带相似度
- **✨ AI 回答**:RAG 模式,检索 top5 小节 → GLM-4-Flash 生成带引用的回答,答案下方列出引用来源笔记

输入后按 Enter = 直接检索。

---

## 6. 图谱:看见你的知识网络

🕸 图谱页:

- **节点** = 已入库笔记,大小随连接数增长,**亮蓝色 = 枢纽**(被引用最多)
- **连线** = `[[双链]]`
- **交互**:拖拽节点重排 · 点击节点 → 高亮它的邻居(其余淡出)+ 右侧面板显示邻居清单(点邻居名字可跳转)· 点空白取消选中
- **右下孤链清单**:指向"还不存在的笔记"的链接——你的知识盲区,也是下一批采集目标

**用法建议**:每周看一次,孤岛笔记(无连线)考虑补链或删除;枢纽笔记值得人工精修。

## 7. 简报与园丁(维护日课)

🌻 今日简报页:

- **统计卡片**:条目/事件/提案/笔记数(24h 与累计)
- **🌻 园丁巡库** → 「开始巡库」:巡库 Agent 扫描 vault,发现孤岛、断链、可补的双链,**产出"追加链接"类提案**进审批台(同样需要你批准才生效)
- **高频标签**:你知识库的主题分布

建议:每天早上开一次巡库,喝口咖啡审掉两三条提案。

## 8. 数据与备份

| 数据 | 位置 | 说明 |
|---|---|---|
| **你的知识** | `vault/*.md` | 纯 Markdown + `[[双链]]`,Obsidian 可直接打开 |
| 过程数据 | `data/loom.db` | 条目/事件/提案,可随时删掉重置 |
| 语义索引 | `data/chroma/` | 可用 `POST /api/reindex` 全量重建,不必备份 |
| 嵌入模型 | `data/chroma_models/` | 79MB,首次检索时自动下载 |

**备份 = 复制 `vault/` 目录**。其余一切都可重建——这就是零锁定。

## 9. 常用环境变量(`.env` 或启动命令)

| 变量 | 默认 | 说明 |
|---|---|---|
| `INSIGHTLOOM_LLM_API_KEY` | 空(=MOCK) | LLM Key |
| `INSIGHTLOOM_LLM_BASE_URL` | DeepSeek 官方 | OpenAI 兼容端点 |
| `INSIGHTLOOM_LLM_MODEL` | deepseek-chat | 模型名 |
| `INSIGHTLOOM_LLM_MOCK` | 0 | `1` 强制 MOCK |
| `INSIGHTLOOM_DATA_DIR` / `VAULT_DIR` | ./data ./vault | 自定义路径 |

> 旧前缀 `CURATOR_*` 完全兼容,老配置不用改。

## 10. 常见问题

- **换端口?** `uvicorn server.app:app --port 8400`,插件 popup 里同步改地址
- **怎么切回演示模式?** `.env` 里 Key 行前加 `#` 注释,重启
- **检索说找不到?** 先 `POST /api/reindex` 重建索引
- **插件连不上?** 确认服务在跑 + popup「测试连接」;地址别多斜杠
- **想清空重来?** 停服务 → 删 `data/loom.db` → 重启(笔记保留,过程数据清零)
