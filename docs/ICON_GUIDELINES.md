# 洞察织机图标设计说明

本项目当前图标为原创几何图形，不使用任何第三方品牌符号、商标轮廓或受保护角色元素。

## 文件

- `web/assets/icon-insightloom-primary.svg`：主图标（品牌展示 / 宣传图）
- `web/assets/icon-insightloom-mark.svg`：简化图标（应用入口 / 小尺寸场景）
- `web/assets/favicon-insightloom.svg`：网页 favicon

## 设计语义

- 书页造型：表示知识与笔记沉淀
- 中轴结构：表示结构化治理流程
- 对勾符号：表示“审批后入库”的可信机制
- 冷色渐变：表示智能工作流与产品感

## 侵权规避原则

- 不使用与现有头部品牌近似的图标结构（如苹果、Google、Notion、Obsidian、OpenAI 等标志性外轮廓）
- 不使用品牌字体字形直接拼接
- 不使用已注册角色或吉祥物元素
- 保留源 SVG 便于后续继续原创迭代
